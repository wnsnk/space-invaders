# Space Invaders
## Description
This is a clone of the Space Invaders Arcade Game i made for the assignment of Day 95 of the 100 Days of Code course. 
### Sprites
I did not create the sprites, I used the following asset packs:
- PIXEL SHMUP FREE:
https://livingtheindie.itch.io/pixel-shmup-ships-free
- SHMUP-Asset-Pack-1:
https://alphawaves.itch.io/shmup-graphics-pack?download

## Installation
- Clone repository, create virtual environment and install dependencies:
```bash
git clone https://github.com/wnsnk/space-invaders/
cd space-invaders
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

- run the game
```bash
python main.py
```
